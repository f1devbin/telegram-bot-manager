# Telegram Bot Manager — вебхуки и настройки бота онлайн

**[Открыть Telegram Bot Manager →](https://f1devbin.github.io/telegram-bot-manager/ru/)**

Бесплатный open-source веб-инструмент для управления Telegram-ботом через Bot API: **установка, проверка (getWebhookInfo) и удаление вебхука**, **команды**, **имя, описание и аватар**, **кнопка меню** и **права администратора по умолчанию**. Без кода, установки и бэкенда: всё работает в браузере.

## Возможности

- **Вебхук:** `setWebhook` с `secret_token` (есть генератор), `allowed_updates`, `max_connections`, фиксированным IP и самоподписанным сертификатом. Удаление вебхука и очистка очереди без потери секретного токена.
- **Проверка getWebhookInfo:** URL, очередь, последняя ошибка доставки и ошибки синхронизации в вашем часовом поясе — с подсказками по SSL, DNS, таймаутам и HTTP-ошибкам.
- **Команды:** редактор `setMyCommands` с проверкой, для всех областей (scope), языков и с флагом `is_ephemeral`.
- **Профиль:** имя, короткое и полное описание для каждого языка. Отправляются только изменённые поля, лимит `429 retry_after` показывается понятно.
- **Аватар:** загрузка фото или видео (`setMyProfilePhoto`) и удаление.
- **Кнопка меню:** команды, Web App (Mini App) или по умолчанию — для всех чатов или одного.
- **Права администратора:** отдельно для групп и каналов, включая новые права Bot API 10.3.
- **Для разработчика:** сырые JSON-ответы, журнал запросов и готовая команда `curl` для каждого действия.
- 5 языков интерфейса, светлая и тёмная темы, адаптивная вёрстка.

## Безопасность

Сайт статический (GitHub Pages), сервера нет. Запросы идут из браузера напрямую на `api.telegram.org` или на выбранный вами сервер API. Токен по умолчанию хранится только в текущей вкладке; кнопка «Отключить» удаляет его. Строгая CSP, без аналитики и сторонних скриптов.

## Если api.telegram.org заблокирован

Разверните [Cloudflare Worker](proxy/cloudflare-worker.js) из репозитория (бесплатного тарифа достаточно) и укажите его URL в разделе «Дополнительно: сервер API». Подробности — в [README на английском](README.md#cors-proxy).

## Запуск у себя

Сделайте форк → **Settings → Pages → Source: GitHub Actions**. Каждый push в `main` прогоняет тесты и публикует сайт. Или локально:

```bash
npm run build && npm run serve
```
